# Phase 3 data catalog

Phase 3 is closed. Data remains in its original stable paths so configs,
hashes, and reports stay reproducible. The machine-readable inventory is
`catalog.json`, generated by:

```bash
python phase3/scripts/maintenance/build_data_catalog.py
```

## Lifecycle groups

| Group | Contents | Policy |
|---|---|---|
| Canonical sources | `source/`, `attempts/`, `apps_pilot/`, `behavior/` | Immutable provenance and natural model outputs |
| Canonical router | `decision_only/` | Final Phase 3 router training corpus |
| Protected evaluation | `two_stage_selective_repair/`, `runs/representation_probe/` | Never use for training or selection |
| Negative experiments | `revised_router/`, `contrastive_pairs/`, `dpo_pilot/`, `semantic_model_dpo/` | Preserve to reproduce rejected results |
| Calibration | `router_calibration_v1/` | Completed; promotion gate failed |
| Incomplete recovery | `router_recovery_v2/current/` | 108 verified pairs; closed below the 200-pair gate |

`router_recovery_v2/full_code_scan/` retains only its compact source-scan
summary and reproduction instructions. Its unexecuted 35,408-generation queue
is not research evidence and is regenerated from the pinned APPS revision if a
future phase explicitly reopens this direction.

Do not add new Phase 3 training rows. A follow-up must create a new phase and
copy only the explicitly selected immutable inputs.
