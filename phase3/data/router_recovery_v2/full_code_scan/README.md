# Full APPS/MBPP source scan

This directory retains the compact summary of an unexecuted source-level scan.
Phase 3 closed before the queue was run. Large source/manifest/batch files were
removed because they are reproducible planning artifacts, not observed data.

## Result

- APPS train scanned: 5,000; structurally eligible before overlap filtering:
  4,450; new eligible sources: 4,087.
- MBPP non-test scanned: 474; new eligible sources: 339.
- Combined new source pool: 4,426.
- Excluded: 322 protected, 24 already admitted, and 152 previously sampled.
- Batch size: 32 sources, eight base-model generations per source.
- Exhaustive queue size: 35,408 generations. Do not run it exhaustively.

APPS priority is introductory, then interview, then competition. MBPP includes
only train, validation, and prompt splits; the frozen test split remains
excluded.

## Historical run policy

The planned policy was to run one APPS batch followed by one MBPP batch and
fresh-verify after every batch. It was never executed. Reproduce the source
scan with `prepare_router_recovery_full_code_scan.py` only in a new phase with
new holdouts; do not resume it as Phase 3.

The source files include dataset reference solutions only for verifier
provenance. A reference solution must not be paired against a model answer.
Both the correct and plausible-wrong members of an admitted pair must be
generated by the same model origin and freshly verified.
